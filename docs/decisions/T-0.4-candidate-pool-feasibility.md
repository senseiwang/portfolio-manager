# 候选池过滤字段可行性确认

> 本文档对照 `CandidatePoolFilterCriteria` 类型（见第 4 节），逐条确认每个过滤条件
> 能否从已探测到的 SDK 返回字段直接算出或间接计算。

## 过滤条件清单

| # | 条件 | 目标值 | 状态 | 说明 |
|---|------|--------|------|------|
| 1 | `minCirculatingMarketCap` | ≥ 50 亿 | ✅ **直接可用** | `FullQuote.circulatingMarketCap` 单位为亿，可直接比较 |
| 2 | `minAvgAmount20d` | ≥ 1 亿 | ⚠️ **需自行计算** | `FullQuote.amount` 是当日成交额（单位：万元），但无法直接从 batch.cn 获取 20 日均值。需通过 `sdk.kline.cn()` 获取近 20 日 K 线，对各日 `amount` 取算术平均，再转换为亿元（注意单位换算：万元→亿元） |
| 3 | `excludeST` | true | ✅ **直接可用** | `FullQuote.name` 包含股票名称，可直接检查是否以 `"ST"`、`"*ST"`、`"SST"`、`"S*ST"` 开头 |
| 4 | `minListedTradingDays` | ≥ 60 天 | ⚠️ **需降级方案** | `FullQuote` 无上市天数字段。降级方案：（A）使用 `sdk.reference.dividendDetail()` 返回的分红记录年份估算是否已上市超过 60 天；（B）或直接从 `sdk.kline.cn()` 可获取的 K 线根数判断（如果返回 K 线数量 ≥ 60 根则满足条件）；（C）或利用 `sdk.calendar` 相关 API 结合 `sdk.quotes.cn` 获取当前价格判断。**推荐方案 B**：因为 K 线获取本身就是候选池扫描的必要环节，无额外调用成本 |
| 5 | `maxLimitUpDaysIn5` | ≤ 3 天 | ⚠️ **需自行计算** | `FullQuote` 无历史涨停记录。需通过 `sdk.kline.cn()` 获取近 5 日 K 线，对各日判断 `close === limitUp`（但 `limitUp` 仅存在于当天行情快照，不存于 K 线历史）。**替代方案**：判断当日收盘价是否接近 `prevClose * 1.1`（涨停 ≈ +10%），对非科创/北交所股票可近似判断。更精确的方案是在盘中通过 `sdk.marketEvent.ztPool()` 检查股票是否出现在涨停池中，但该方法无法回溯历史。**推荐方案**：使用 K 线 `changePercent >= 9.5%` 近似判断涨停日，近 5 日累计 ≤3 天即满足条件 |
| 6 | `maxAvgAmplitude20d` | ≤ 10% | ⚠️ **需自行计算** | `FullQuote.amplitude` 仅包含当日振幅。20 日平均振幅需通过 `sdk.kline.cn()` 获取近 20 日 K 线，对各日的 `amplitude` 取算术平均 |

## 综合结论

| 维度 | 操作成本 | 依赖的数据源 | 实现可行性 |
|------|---------|-------------|-----------|
| 流通市值 ≥ 50亿 | 0 次额外调用（直接读 batch.cn） | batch.cn | ✅ 简单 |
| 排除 ST | 0 次额外调用（直接读 batch.cn） | batch.cn | ✅ 简单 |
| 日均成交额 ≥ 1亿 | 1 次 kline.cn 调用/股 | kline.cn | ⚠️ 中等 |
| 上市天数 ≥ 60 | 0 次额外调用（复用 K 线数据） | kline.cn | ⚠️ 中等 |
| 5 日涨停次数 ≤ 3 | 0 次额外调用（复用 K 线数据） | kline.cn | ⚠️ 中等（近似判断） |
| 20 日平均振幅 ≤ 10% | 0 次额外调用（复用 K 线数据） | kline.cn | ⚠️ 中等 |

> **关键发现**：6 个过滤条件中有 4 个（#2, #4, #5, #6）需要 K 线数据，而 K 线获取本身就是候选池扫描的必经环节（后续信号计算也需要 K 线），因此**并非额外调用成本**。真正对 batch.cn 数据做过滤的只有 #1（市值）和 #3（ST），这两个条件应作为**前置快速过滤**，先用 batch.cn 数据大幅缩小候选池范围，然后再对有资格的股票拉取 K 线做后续条件计算。

## 推荐实现策略

```
1. 调用 sdk.batch.cn() 获取全市场行情
2. 前置快速过滤（无需额外数据）：
   ├── circulatingMarketCap >= 50 亿  (条件 #1)
   └── !name.startsWith("ST")         (条件 #3)
3. 对通过前置过滤的股票，批量拉取近 20 日 K 线
4. K 线过滤（复用已有数据）：
   ├── avg(amount) >= 1亿              (条件 #2)
   ├── kline.length >= 60              (条件 #4)
   ├── count(changePercent >= 9.5) <= 3 (条件 #5)
   └── avg(amplitude) <= 10%           (条件 #6)
5. 通过全部条件的股票进入候选池
```

## 未解决的风险

- **K 线数据量**：如果全市场 5000+ 只股票中的 2000 只通过前置过滤，需要拉 2000 次 kline.cn 调用。需通过 `sdk.batch.byCodes()` 先缩小范围，或使用 `stock-sdk` 的 rateLimit 控制并发。
- **涨停近似判断**：对于科创板（涨跌幅 ±20%）和北交所（±30%），`changePercent >= 9.5%` 不再适用。需在过滤时检查 `marketId` 区分板块。
